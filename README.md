## О проекте

Одностраничный сайт о профориентационной работе Сальского индустриального техникума:

- дни открытых дверей
- выездные профориентационные уроки
- консультации для абитуриентов (школьники 8–9 классов)

В проекте: текст, инфографика, блоки под фото, интерактивный мини-тест, контакты.

---

## Как открыть локально

1. Скачайте или клонируйте репозиторий
2. Откройте файл `index.html` в браузере

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub
2. Загрузите файлы (`index.html` и `README.md`)
3. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` → Folder: `/ (root)`
4. Через 1–2 минуты сайт будет доступен по адресу:  
   `https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`
